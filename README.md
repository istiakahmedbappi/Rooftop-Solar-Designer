# Rooftop Solar Designer (Bangladesh)

By Istiak Ahmed Bappi · Sustainable Energy Solution BD (SESBD) · sustainableenergysolutionbd@gmail.com

A single-file, browser-based tool for pre-feasibility design of rooftop solar plants in Bangladesh.
Open `index.html` in a browser. No server, build step or install is needed.

## What it does
- Roof from a satellite screenshot, a live map, a typed size, or Manual draw (feet or metres)
- 3D editor: obstacles (tank, stair room, tree, side building), panels on top of obstacles, panel direction, tilt, vertical or horizontal panels, 1 to 4 panels stacked per table
- Automatic layout of panels, DC and AC cables, trays, inverter, net meter, earthing and lightning rods
- Single line diagram and a technical and financial report with project details
- Project save and open (file and browser auto-save)

## Put it online with GitHub Pages
1. Create a repository on GitHub and upload all files from this folder (keep the file name `index.html`).
2. Open the repository, then Settings, then Pages.
3. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
4. After a minute the site is at `https://<your-user-name>.github.io/<repository-name>/`.

## Notes
- The 3D view loads three.js and map tiles from the internet, so the page needs a connection.
- Results are a pre-feasibility estimate. Prices, tariff and yield figures are editable defaults and must be checked against current quotes, tariff orders and a site survey.
- Add a license file if you want others to reuse the code. None is included.
